01 / FIELD NOTES

第一个完整合约：MessageBoard

保存公开消息，仅允许部署者修改。

// SPDX-License-Identifier: MIT
pragma solidity 0.8.30;

/// @notice Teaching contract: only its deployer may update a public message.
contract MessageBoard {
    address public immutable owner;
    string public message;

    error NotOwner();
    event MessageChanged(address indexed author, string newMessage);

    constructor(string memory initialMessage) {
        owner = msg.sender;
        message = initialMessage;
    }

    function setMessage(string calldata newMessage) external {
        if (msg.sender != owner) revert NotOwner();
        message = newMessage;
        emit MessageChanged(msg.sender, newMessage);
    }
}

构造函数初始化 owner 与 message。Immutable 使所有者值在部署后不可变，Public 生成读取接口。setMessage 检查调用者、写入状态并发出事件。NotOwner 是自定义错误。示例不处理支付，也没有隐藏数据。

02 / FIELD NOTES

通过状态及调用学习语言

类型、数据位置及可见性描述不同属性。

特性本例含义
address账户 / 合约地址，不是身份证明
msg.sender当前调用的直接调用者，可以是另一合约
string memory构造输入位于临时内存
string calldata只读外部调用输入位置
external / public可调用接口及公共访问接口
private语言可见性限制，不是公链保密
revert终止执行并回滚其状态变化，仍可能收费

03 / FIELD NOTES

测试权限边界，而不只是成功路径

仓库包含真实本地 EVM 测试。

验收包括：部署保存初始消息；所有者可修改；事件包含预期作者及文字；其他账户收到 NotOwner 且不能改变状态。只测试部署成功会漏掉访问控制的目的。

项目使用 Solidity 0.8.30、优化器 200 次及 Shanghai EVM 目标。这是固定教学设置，不是最新版声明。编译器及库升级后需重新检查警告、字节码与行为。最小合约没有升级路径或所有权转移函数。
