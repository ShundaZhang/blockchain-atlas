01 / FIELD NOTES

路径 A · 在 Remix VM 创建第一个合约

首次运行无需浏览器钱包或真实资金。

步骤操作
打开打开原始 Remix IDE，创建 MessageBoard.sol
编译粘贴 Solidity 章节合约，选择编译器 0.8.30 及 Shanghai EVM 目标
部署选择 Remix VM、账户 A，以及 "Hello" 等初始字符串
观察读取 owner / message，用 A 调用 setMessage，检查事件 / 回执
拒绝切换 B 尝试 setMessage，确认拒绝且状态未变

在 Remix 使用 StudyToken 时，将 npm 导入替换为下面带版本导入，以相同编译器 / 目标编译。Recipient 参数须为 VM 账户地址，而非 ENS 名称或简称。部署后读取 decimals、totalSupply 及 balanceOf。

import {ERC20} from "@openzeppelin/contracts@5.4.0/token/ERC20/ERC20.sol";

02 / FIELD NOTES

路径 B · 运行可下载本地项目

编译及合约执行已在本地 EVM 测试。

下载解压 examples.zip。使用支持的 Node.js 版本（本站验证为 Node 24.10.0）。锁文件固定依赖。编译使用本地 solc，Hardhat 提供本地开发节点。在项目目录打开两个终端。

npm ci
npm run compile
# Terminal A
npm run node
# Terminal B
npm test
npm run demo

预期结果：两个合约编译，两组测试通过；演示显示供应 1,000,000 STUDY、Bob 余额 29 STUDY、剩余授权 6 STUDY 及修改后消息。地址及交易哈希依运行而异。脚本仅接受本机链 31337，无需助记词或私钥。

03 / FIELD NOTES

路径 C · 理解公开测试网部署流程

这是完成本地检查后的手动进阶流程。

核对当前网络指南，选择 Sepolia 等应用测试网、独立测试钱包及适用水龙头 / RPC。获取测试 ETH，确认 Chain ID，以固定源码编译，并经明确测试网连接部署。检查构造参数、回执状态、地址、供应及所有者权限。

可用时公开源码及编译设置进行浏览器验证，用测试账户检查读取、转账、授权及拒绝路径。水龙头 / RPC 可能需要账号或有限制。所提供脚本明确不自动执行公开部署，也不接收生产凭据。

主网部署、分配、交易所上架及提供流动性是具有不同后果的独立步骤。代币部署不会完成这些操作。应将学习练习与真实资产发行或销售分开。
