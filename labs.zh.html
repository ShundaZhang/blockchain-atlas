改变一项假设

三项本地教学模型，无钱包、公开 RPC、代币转移、上传或练习输入保存。哈希使用浏览器 SHA-256，并非 Bitcoin 序列化或 Ethereum Keccak。

哈希链接代币授权AMM 报价
01 / HASH LINKS

重新链接历史不等于授权历史

原内容：Alice pays Bob 5。修改后比较保留与重建后续链接。区块仅包含编号、内容及前一个摘要。

就绪 — 选择输入

保留原链接时，第一区块改变会破坏下一引用。全部后续链接重建后，玩具历史可重新内部一致，但未检查共识、签名、难度或最终性。这解释了哈希链为何不是完整区块链。

02 / ERC-20

余额与授权都必须允许转移

简化普通有限授权，无代币费用、钩子或特殊无限授权行为。

就绪 — 选择输入

模型计算所有者余额、接收方增加量及剩余额度。尝试超过额度，再尝试超过余额；失败保持所有状态不变。下载 ERC-20 已在 EVM 测试，此浏览器模型不是合约部署。

03 / DEFI

兑换改变储备比例

v2 式恒定乘积报价，费用保留池内。数字均为合成，浮点输出为近似值。

就绪 — 选择输入

effectiveInput = input × (1 − fee)
output = reserveY × effectiveInput / (reserveX + effectiveInput)
newX = reserveX + input
newY = reserveY − output

若计算输出低于最小值，模型拒绝兑换并保留原储备。它不模拟其他交易者、MEV、代币舍入、集中流动性或实时价格。
