01 / FIELD NOTES

A complete first contract: MessageBoard

Store a public message and permit only its deployer to change it.

// SPDX-License-Identifier: MIT
pragma solidity 0.8.30;

/// @notice Teaching contract: only its deployer may update a public message.
contract MessageBoard {
    address public immutable owner;
    string public message;

    error NotOwner();
    event MessageChanged(address indexed author, string newMessage);

    constructor(string memory initialMessage) {
        owner = msg.sender;
        message = initialMessage;
    }

    function setMessage(string calldata newMessage) external {
        if (msg.sender != owner) revert NotOwner();
        message = newMessage;
        emit MessageChanged(msg.sender, newMessage);
    }
}

The constructor initializes owner and message. immutable stores an unchangeable owner value in deployed code semantics; public generates read accessors. setMessage checks the caller, writes state and emits an event. NotOwner is a custom error. There is no payment or hidden data in this example.

02 / FIELD NOTES

Learn the language through state and calls

Types, data location and visibility describe different properties.

FeatureMeaning in this example
addressAn account/contract address, not an identity certificate
msg.senderImmediate caller of the current call; can be another contract
string memoryConstructor input used in temporary memory
string calldataRead-only external call input location
external / publicCallable interface versus generated/public access
privateLanguage visibility restriction, not secrecy on a public chain
revertAbort execution and undo its state changes; gas can still be charged

03 / FIELD NOTES

Test the authority boundary, not only the happy path

The repository includes actual local EVM tests.

Acceptance checks: deployment stores the initial message; the owner can change it; the event contains the expected author and text; another account receives NotOwner and cannot change state. A test that only deploys successfully misses the purpose of access control.

The project uses Solidity 0.8.30, optimizer 200 runs and EVM target shanghai. These are pinned teaching settings, not a latest-version claim. Compiler and library upgrades require rechecking warnings, bytecode and behavior. The minimal contract has no upgrade path or ownership-transfer function.
