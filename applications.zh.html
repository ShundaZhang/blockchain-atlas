01 / FIELD NOTES

应用组合公开状态与外部系统

明确链上确定什么、什么仍在链下。

应用链上作用保留依赖
支付签名转移与共同结算记录密钥托管、网络访问及兑换路径
资产代币化转移规则与记录现实权利、托管方及可执行性
溯源带时间承诺及共享更新初始数据真实性及传感器 / 运营者完整性
DAO 金库提案执行与资产控制策略参与、投票集中及链下协调
凭证发行者承诺或撤销状态身份绑定、隐私及发行者信任

02 / FIELD NOTES

代币记录不等于物品相关全部权利

同质化及非同质化接口表示不同状态模型。

同质化代币跟踪可互换单位；NFT 通常跟踪独立 Token ID 及持有者。元数据或 URI 可描述物品，而无需把物品本身放在链上。持有代币本身不确定版权、现实所有权或关联媒体永久可用。

设计应用时，应将资产语义与传输语义分开。谁能更新元数据、撤销凭证或改变可升级合约？即使转移公开可见，这些问题仍存在。

对应资料：Smart contract introduction ↗ · Web3 concepts ↗

03 / FIELD NOTES

从协调问题开始

共享数据库可能是更好的工程选择。

询问参与者是否需要独立验证、是否接受一个管理员、公开可见是否适合数据，以及错误如何恢复。区块链应解决真实协调与信任问题。不能仅因项目称为 Web3 就加入可转移代币。

好的设计文档列出状态转换规则、权限图、链下依赖、隐私边界及退出 / 恢复机制。应独立评估这些内容，不与募资或价格叙事混合。

对应资料：Web3 concepts ↗ · Smart contract security ↗
