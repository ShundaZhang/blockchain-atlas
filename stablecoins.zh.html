01 / FIELD NOTES

稳定币需要代币接口之外的锚定机制

询问可以赎回什么、由谁赎回、对应哪些资产。

设计机制关键依赖
储备担保发行方按储备 / 赎回安排创建代币储备资产、托管、发行方条款与流动性
加密资产抵押锁定抵押品与清算规则抵押品价值、预言机新鲜度与清算能力
算法 / 内生担保供应变化或相关代币激励试图维持目标信心、反身性及可用外部担保

类别可以重叠。交易所锚定报价是市场观察，不等于持有者能够向发行方行使赎回。即使智能合约正常运行，代币也可能偏离目标价格。

02 / FIELD NOTES

USDT 结合链上转移与中心化发行方

去中心化结算基础设施不会消除发行方权限。

Tether 发布 USD₮ 支持协议、储备披露及服务 / 赎回条款。这些记录识别发行方认可部署；另一合约使用同一 USDT 简称并不足够。链上代币是一层，储备、银行、托管及赎回属于链下安排。

发行方控制的代币实现可包含特殊发行权限，以及按相应机制冻结 / 黑名单等限制。应检查具体链实现与当前条款。储备鉴证是具有日期及范围的披露，不是所有储备资产的连续链上验证。

对应资料：Tether supported protocols ↗ · Tether transparency ↗ · Tether terms ↗

03 / FIELD NOTES

链、合约、单位及转账行为都重要

不能把 STUDY 示例假设套用于所有真实代币。

Ethereum USD₮ 与 TRON USD₮ 位于不同执行及费用环境，转账需要对应网络费用资产。解释地址前应核对发行方支持及精确代币合约。精度不是通用 18 位，应读取实际合约，而非照搬 STUDY 设置。

部分既有合约缺少标准布尔返回值，或要求先归零再设新非零授权。OpenZeppelin SafeERC20 提供兼容辅助，但不会让不可信代币在所有意义上安全。应阅读实现并测试集成。

对应资料：Tether supported protocols ↗ · OpenZeppelin token API ↗
