01 / LEARNING ROUTE

From concepts to executable behavior

Assumes basic programming and systems knowledge. The browser exercises need no wallet; the downloadable project uses only a local development chain.

01

Learn the system and the ideas

Foundations → History → Money & Web3 → Cryptography → Consensus. Explain what is decentralized, who can issue assets, and what each cryptographic check proves.

02

Follow a transaction

Bitcoin → Ethereum → Transactions → Contracts. Distinguish a UTXO from account state, token units from ETH, and execution success from finality.

03

Create and inspect contract behavior

Solidity → Create a token → Practice. Compile MessageBoard and StudyToken, deploy on a local EVM and test authorized and rejected operations.

04

Analyze applications and dependencies

Stablecoins → DeFi → Scaling & Cross-chain → Applications → Security / Labs. Read rollups, Lightning, interoperability and the dated Web3 snapshot. Map backing, oracles, bridge assumptions, upgrade powers and exit paths.
