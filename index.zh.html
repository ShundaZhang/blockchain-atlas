01 / LEARNING ROUTE

从概念到可执行行为

假设具有基本编程及系统知识。浏览器练习无需钱包，下载项目仅使用本地开发链。

01

理解系统及理念

原理 → 历史 → 货币与 Web3 → 密码学 → 共识。解释什么去中心化、谁能发行资产，以及密码学检查证明什么。

02

跟踪一笔交易

Bitcoin → Ethereum → 交易 → 合约。区分 UTXO 与账户状态、代币单位与 ETH，以及执行成功与最终性。

03

创建并检查合约行为

Solidity → 发行代币 → 实践。编译 MessageBoard 与 StudyToken，在本地 EVM 部署，测试授权及拒绝操作。

04

分析应用及依赖

稳定币 → DeFi → 扩容与跨链 → 应用 → 安全 / 练习，阅读 Rollup、闪电网络、互操作及注明日期的 Web3 进展。画出担保、预言机、桥假设、升级权限与退出路径。
